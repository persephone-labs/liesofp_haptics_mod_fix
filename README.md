Very short python script that you can run against the main.dll file of the Lies of P DualSense Haptic Feedback mod found at Nexus mods - https://www.nexusmods.com/liesofp/mods/514 that will make the adaptive triggers and lightbar work if using USB to raspberrypi pico software to give DualSense PS5 controllers bluetooth and haptics.

Much respect to the original author of the Haptics mod, it is incredible.
